01 / PONTO DE PARTIDA

Cada espaço tem
uma lógica própria.

O projeto HVAC começa pela leitura do empreendimento: sua finalidade, características físicas e necessidades de operação. A partir dessas informações, a DPG desenvolve a documentação técnica prevista para o escopo acordado.

Projetar. Documentar.
Coordenar.

Atuação dedicada a projetos HVAC e documentação técnica. O escopo e os documentos são definidos conforme as características de cada empreendimento.

03 / INTENÇÃO DE PROJETO

Clareza técnica
para as decisões
que vêm depois.

Um projeto organiza premissas, desenhos e informações para orientar as próximas etapas do empreendimento. Execução e implantação pertencem a escopos próprios.

PROJETO ≠ EXECUÇÃO

04 / COMO TRABALHAMOS

Um percurso
bem definido.

Alinhamento de informações e limites do escopo fazem parte do desenvolvimento de um projeto claro.

01

Entendimento

Conhecer a finalidade do espaço, as necessidades informadas e os dados disponíveis.

02

Premissas

Alinhar critérios, interfaces e entregáveis previstos para o trabalho.

03

Desenvolvimento

Elaborar os documentos e desenhos técnicos contemplados no escopo acordado.

04

Entrega

Organizar a documentação do projeto para apoiar as etapas seguintes do empreendimento.

As etapas e os documentos podem variar de acordo com as características e as atribuições aplicáveis a cada contratação.
